🛠 Инструменты

1. Kling Motion Control

Платный SaaS (китайский, от Kuaishou). Даёт 4K качество видео. Самый простой вариант: загрузил фото + видео → получил результат.

Плюсы: не нужен GPU, работает в облаке, минимальный порог входа
Минусы: слишком "идеальное" видео — палится как AI. Kling 2.6 пока непревзойдён, open source отстаёт.

2. ComfyUI + Wan 2.2 Animate

ComfyUI — open-source нодовый интерфейс для нейросетей. Wan 2.2 — AI-модель от Alibaba для анимации персонажей по видео-референсу. Заменяет лицо/тело в реальном видео, сохраняя движения и мимику. Фон остаётся живой → выглядит реалистичнее.

Модель: wan2.2_animate_14B_bf16.safetensors

Плюсы: "шакальное" качество = плюс для TikTok (не палится), полный контроль, масштабируемость
Минусы: высокий порог входа, нужен GPU

Wan Animate God Mode V3 (HearmemanAI)

Премиальный workflow для ComfyUI от HearmemanAI (Hearmeman98). Production-ready pipeline.

  • Character swap — полная замена персонажа
  • Face swap — замена лица с сохранением мимики
  • Auto masking — автоматическое маскирование
  • Background swap, встроенный upscaler, LoRA support

Доступ: Платный — через Whop ($25–35/мес "Hideout" уровень)

3. ReelShift (reelshift.xyz)

SaaS-сервис "для чайников" — обёртка над аналогичной технологией. Загрузил 2–3 фото → вставил ссылку на TikTok/Reel → получил видео.

Плюсы: нулевой порог входа
Минусы: зависимость от сервиса, нет контроля

4. Nano Banana Pro

Генератор изображений на базе Google Gemini 2.5 Flash / Gemini 3 Pro. Сохраняет консистентность лица между генерациями. Используется для создания исходных фото AI-модели.

🤖 Автоматизация через Nex

  • ✅ Парсинг залетевших видео — тренды, скачивание, анализ
  • ✅ Промпты — positive/negative для Wan
  • ✅ Скрипты автоматизации — batch-обработка, очереди
  • ✅ Постинг-стратегия — когда, что, куда
  • ✅ Аналитика — просмотры, вовлечённость, ROI

Схема конвейера

G находит тренд → Nex скачивает видео → Nex отправляет в ComfyUI API на RunPod → генерация → Nex забирает результат → G одобряет → Nex постит

ComfyUI API (подключение)

  • POST /prompt — отправить workflow на генерацию
  • WebSocket /ws — отслеживать прогресс в реальном времени
  • GET /history — получить результаты

Nex может через curl отправлять задачи напрямую. Полная автоматизация без браузера.

🚀 План запуска

  1. Регистрация на RunPod → пополнить баланс ($10–25 для старта)
  2. Купить подписку HearmemanAI на Whop ($25/мес Hideout) → получить God Mode V3
  3. Задеплоить шаблон: get.runpod.io/wan-template → 5 мин, ComfyUI + модели готовы
  4. Загрузить God Mode V3 workflow → тест + настройка
  5. Nex подключается через API → автоматизация
