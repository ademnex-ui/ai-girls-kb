1. WAN 2.2 ANIMATE

Простыми словами: Open-source AI-модель от Alibaba — берёт фото персонажа + видео с движениями → создаёт видео где персонаж с фото повторяет эти движения (motion transfer).

Два режима:

  • Animate — фото оживает по движениям из видео-референса
  • Replace — заменяет персонажа в существующем видео

Технически:

  • Модель: Wan2.2-Animate-14B (14B параметров)
  • 720P, 24fps
  • Архитектура MoE (Mixture of Experts) — первая такая в видео-диффузии
  • Open-source, веса на HuggingFace
  • Выпущена 28 июля 2025, Alibaba/Tongyi Lab

Чем лучше Wan 2.1:

  • MoE архитектура: 27B параметров, активируются только 14B за шаг
  • +65% больше обучающих изображений, +83% видео
  • Добавлена функция Animate (в 2.1 не было)
  • Лучше temporal consistency (меньше "прыжков" между кадрами)

Ссылки:

  • GitHub официальный

2. NSFW LoRA

Что такое LoRA (Low-Rank Adaptation):
Способ дообучить большую AI-модель под конкретную задачу не переобучая всю модель. Маленький файл (.safetensors, 20-200 МБ) — "шпаргалка" которую добавляют к базовой модели.

Аналогия: Базовая модель = художник-универсал. LoRA = шпаргалка с примерами "рисуй вот так".

Технически:

  • Замораживает оригинальные веса
  • Добавляет матрицы низкого ранга к трансформерным блокам
  • Вместо 7B параметров обучается только 1-10M дополнительных
  • Вес применения: 0.5-1.5 (чем выше — тем сильнее влияние)
  • Arxiv paper

Два типа NSFW LoRA:

  1. Стилистическая — учит модель рисовать откровенный контент в стиле (реализм, аниме...)
  2. Персонажная (Character LoRA) — учит воспроизводить конкретного персонажа/человека

Где берут: CivitAI, Tensor.Art, самообучение через Kohya_ss

4. WORKFLOW С ЛОРАМИ (ComfyUI)

ComfyUI — open-source визуальный редактор нод для Stable Diffusion. Каждый шаг генерации = нода. Все ноды вместе = workflow. Сохраняется как JSON, можно делиться.

Типичные ноды NSFW workflow:

  • Load Checkpoint → базовая модель
  • Load LoRA × N → несколько LoRA одновременно
  • CLIPTextEncode → промпты (позитивный + негативный)
  • KSampler → сам процесс диффузии
  • ControlNet Apply → контроль позы
  • UltimateSDUpscale → апскейл
  • FaceDetailer → улучшение деталей лица
  • ReActor → face swap

На CivitAI в разделе Workflows публикуют готовые JSON под конкретные задачи.

Ссылки:

  • ComfyUI на GitHub
  • Workflows на CivitAI

5. Z-IMAGE

Что это: Open-source AI-модель для генерации изображений от Alibaba (Tongyi Lab). Полное название: ZaoXiang (造像 — "создание образов").

Почему популярна для NSFW:

  • Открытые веса → запускается локально
  • Без цензуры, без ограничений
  • Полный контроль над генерацией

Технически:

  • 6B параметров
  • Архитектура S3-DiT (Single-Stream Diffusion Transformer)
  • Требования: от 6-8 GB VRAM
  • Z-Image-Turbo: генерирует 1024×1024 за секунды на consumer GPU

Варианты: Turbo (быстро), Base (детальнее), Pro (лучшее качество)

Ссылки:

  • z-image.ai
  • NSFW туториал

6. «ФОРМА ДЕВУШКИ» — что это технически

Создание консистентного визуального образа персонажа через серию изображений с разных ракурсов. Цель — датасет для обучения персональной LoRA.

Почему много ракурсов:
При обучении LoRA нейросеть должна "понять" как персонаж выглядит с разных точек зрения.

Стандартный набор:

  • Фронталь (прямо) — 30-40%
  • 3/4 (немного сбоку) — 30%
  • Профиль (сбоку) — 15%
  • Сзади — 10%
  • Снизу/сверху — 5%
  • Крупный план лица — отдельно

Для NSFW добавляют: разные позы тела, выражения, освещение, фон (чтобы фон не запомнился как часть персонажа).

7. ДАТАСЕТ ДЛЯ ОБУЧЕНИЯ LORA

Что такое датасет: Набор изображений + текстовые описания (captions). Каждому фото → .txt файл с тегами.

Сколько изображений нужно:

Пошаговая подготовка:

  2. Кадрирование до квадрата (512×512, 1024×1024)
  3. Автокапшенинг (WD14 Tagger, BLIP2, Florence-2)

8. «ГОТОВАЯ ФОРМА ИЗ КОТОРОЙ ЛЕПЯТ СЮЖЕТ»

После обучения LoRA ты получаешь файл .safetensors — персонаж "сохранён" в нём. Теперь можешь:

  • Генерировать любые изображения с этим персонажем
  • Менять сцены, позы, освещение, одежду
  • Комбинировать с другими LoRA
  • Использовать как reference image для видео через Wan 2.2

Персонаж = "актёр", которого можно поместить в любую "сцену".

9. FACE SWAP ЧЕРЕЗ FLUX 2

Что такое FLUX 2:
FLUX.1 (и FLUX 2 / FLUX Pro) — серия диффузионных моделей от Black Forest Labs (команда создателей Stable Diffusion). Считается лучшей open-source моделью для фотореалистичной генерации на 2025-2026 год.

Face swap через FLUX — два способа:

Способ 1 — IP-Adapter FaceID:

  • Берёт референсное лицо → встраивает в генерацию
  • Нода: IP-Adapter FaceID Plus в ComfyUI
  • Сохраняет черты лица при смене сцены/позы

Способ 2 — ReActor (постпроцессинг):

  • Генерирует изображение → заменяет лицо на целевое
  • Использует InsightFace для детекции и замены
  • Работает как нода в ComfyUI

Почему FLUX лучше для этого:

  • Лучше понимает промпты (следование инструкциям)
  • Выше качество деталей кожи и лица
  • Более реалистичное освещение

Ссылки:

  • FLUX на HuggingFace
  • ComfyUI FLUX guide
  • ReActor нода

10. ПОЧЕМУ KLING/GROQ/BANANA БЛОКИРУЮТ NSFW

Kling (Kuaishou): Коммерческий SaaS — строгая модерация, блокирует любой откровенный контент на уровне детектора. Нарушение ToS → бан аккаунта.

Groq: Это вообще не видеогенератор — это инференс-платформа для LLM (языковых моделей). Автор имел в виду облачные GPU сервисы типа Groq Cloud.

Banana.dev: Облачный деплой AI-моделей. Явно запрещает NSFW в ToS. Автоматическая модерация контента.

Почему коммерческие сервисы блокируют:

  1. Юридические риски (CSAM, авторские права)
  2. Репутационные риски
  3. Банковский комплаенс (Visa/MC правила для платформ)
  4. Регуляторное давление (EU AI Act, US законодательство)

Решение — локальный стек: ComfyUI на своём железе или RunPod (арендованный GPU) — никакой модерации, полный контроль.
