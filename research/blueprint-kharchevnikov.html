- Источник лиц: Pinterest — ищет фото двух красивых девушек

- Метод: загружает 2 фото реальных девушек → просит AI "соединить их внешность"

Создал НЕ одну, а 4 модели одновременно:

Почему 4: "Всегда залетает то, о чём даже не думаешь" — тестирование гипотез.

Почему залетело (мой анализ):
- 🎯 Эмоциональный крючок — история буллинга → сочувствие → вовлечение
- 🎯 Нарратив трансформации — "была странной → стала красоткой"

❓ Почему именно Диана Зука залетела (а не 3 другие)

  1. Уникальность > красота. Типичная блондинка = одна из тысяч. Девушка с родимым пятном + аниме = незабываемая.
  2. Сторителлинг. У Дианы была ИСТОРИЯ (буллинг → принятие → сила). У других моделей — только внешность.
  3. Нишевая аудитория. Аниме-фанбаза = лояльная, активная, вовлечённая.
  4. Карусель ≠ стандартный AI-контент. Все AI-модели постят липсинки. Карусель — неожиданный формат.
  5. Эмоциональный резонанс. Буллинг = тема, которая касается ВСЕХ. Лайки/комменты = алгоритм продвигает.

Вывод: Залетает НЕ самая красивая модель, а самая ЗАПОМИНАЮЩАЯСЯ с лучшей ИСТОРИЕЙ.

Подключение к RunPod API

Да, можно. ComfyUI имеет REST API:
- Endpoint: POST /prompt — отправить workflow на генерацию
- WebSocket: /ws — отслеживать прогресс в реальном времени
- GET /history — получить результаты
- Nex может через curl отправлять задачи напрямую

Схема:

Nex (curl) → RunPod IP:8188/prompt → ComfyUI обрабатывает
                                          ↓
Nex (curl) ← RunPod IP:8188/history ← результат (видео)

Для этого нужно:
1. Задеплоить RunPod pod
2. Открыть порт 8188 (HTTP API ComfyUI)
3. Nex подключается по IP:8188
4. Загружает reference image + driving video через API
5. Запускает workflow
6. Забирает готовое видео

Полная автоматизация без браузера. ✅
