ШАГ 0
Подготовка RunPod (один раз)

0.1 Регистрация

  1. Идёшь на runpod.io
  2. Sign Up → email + пароль
  3. Billing → Add Credits → минимум $25-50 для старта
Оплата из РФ: крипта (USDT/BTC) — самый надёжный вариант. Подробнее в Шаге 10.7.

0.2 Создание Network Volume (делается ДО Pod)

Network Volume = жёсткий диск в облаке. Модели скачиваются ОДИН РАЗ и остаются навсегда — даже когда Pod выключен.
  1. Storage → Network Volumes → + Network Volume
  2. Name: ai-girls-storage | Size: 100 GB
  3. Region: тот же что и для Pod (EU-RO-1 или US-TX-3)
  4. Create → ~$7/мес постоянно

ШАГ 1
Разворачиваем ComfyUI на RunPod

1.1 Создание Pod

  1. Pods → + Deploy
  2. GPU: RTX 4090 (~$0.74/час). Если нет → RTX A6000 ~$0.79/час
  3. Template: ComfyUI → официальный "RunPod ComfyUI"
  4. Edit Template: Container Disk = 20 GB | Volume Disk = 0
  5. Attach Network Volume: ai-girls-storage
  6. Expose Ports: добавь 8188
  7. Deploy On-Demand → Pod запустится за ~2-3 мин

1.2 Подключение к ComfyUI

  1. Pod запустился → кнопка Connect
  2. HTTP Service [Port 8188] → ComfyUI открывается в браузере ✅

ШАГ 4
Обучение LoRA персонажа (Kohya_ss)

  1. Pods → Deploy | GPU: RTX 3090 ~$0.44/час или A40 ~$0.76/час
  2. Template: Kohya → "Kohya LoRA Training"
  3. Подключи тот же Network Volume ai-girls-storage

4.2 Установка Kohya_ss

cd /workspace
git clone https://github.com/bmaltais/kohya_ss
cd kohya_ss
pip install -r requirements.txt
python kohya_gui.py --listen 0.0.0.0 --server_port 7860 &

Порт 7860 → веб-интерфейс Kohya

mkdir -p /workspace/dataset/10_mygirl

Utilities → BLIP Captioning | Image folder: путь к датасету | Prefix: mygirl, → Run

ШАГ 6
Анимация видео (Wan 2.2 Animate)

⚠️ Сначала установи ноды Wan 2.2 из Шага 9 — без них workflow не загрузится.

6.1 Скачиваем видео-референс

SnapTik.app или SSSTik.io → вставь ссылку TikTok → скачай без водяного знака.
Нужно видео с движениями тела без крупного плана лица (танец, походка).

6.2 Workflow

👉 github.com/Wan-Video/Wan2.2/tree/main/examples

  1. Load → Wan 2.2 workflow
  2. Reference Image → фото персонажа
  3. Reference Video → видео с движениями
  4. Generate → персонаж повторяет движения
~5-15 минут на RTX 4090 для клипа 3-5 секунд.

ШАГ 7
Face Swap (опционально)

Нода ReActor в ComfyUI:

  • Source Face: фото AI-персонажа (крупный план лица)
  • Target: видео или фото с нужным лицом
  • Face Index: 0
  • Upscaler: GFPGAN или CodeFormer

ШАГ 8
CivitAI: верификация 18+ NEW

Обязательно перед скачиванием NSFW моделей. Без верификации NSFW скрыт, API вернёт 401 Unauthorized.

8.1 Включить Mature Content

  1. Регистрация на civitai.com
  2. Профиль → Settings → Account
  3. Content Preferences → Show mature content (18+)
  4. Подтвердить (просто галочка, документы не нужны) → Сохранить

8.2 API-ключ для wget

  1. Account Settings → API Keys → Add API Key
  2. Называешь ключ (например runpod) → копируешь
  3. Добавляешь во все wget команды:
wget --header="Authorization: Bearer ВАШ_API_КЛЮЧ" \
  -O "model.safetensors" \
  "https://civitai.com/api/download/models/XXXXXX"

ШАГ 9
Установка Wan 2.2 нод в ComfyUI NEW

Обязателен перед Шагом 6. Без нод workflow Wan 2.2 не откроется — ошибка "unknown node type". 
cd /workspace/ComfyUI/custom_nodes

git clone https://github.com/kijai/ComfyUI-WanVideoWrapper
cd ComfyUI-WanVideoWrapper
pip install -r requirements.txt

# Для работы с видео (загрузка, сохранение)
cd /workspace/ComfyUI/custom_nodes

Перезапускаем ComfyUI:

После перезапуска в ComfyUI появятся ноды в категориях WanVideo и VideoHelperSuite.

ШАГ 10
Публикация на Fanvue NEW

Fanvue — OnlyFans-альтернатива, официально разрешающая AI-контент. Комиссия 15% (у OnlyFans 20%).

10.1 Регистрация

  1. fanvue.com → Sign Up → Creator
  2. Username = имя персонажа (менять сложно, выбирай сразу)
  3. Верификация email

10.2 Верификация личности (для выплат)

Загружаешь паспорт/права + selfie. Срок: 1-3 рабочих дня.
Верификация на тебя как владельца — не на AI-персонажа.

10.3 Настройка профиля

  • Profile photo: лучший кроп лица персонажа
  • Cover: широкий кадр 1920×1080
  • Bio: от лица персонажа (имя, история, характер)
  • Цена подписки: $9.99–14.99/мес для старта
  • Важно: укажи в bio что контент создан AI — Fanvue требует

10.4 Первый контент

  • Загрузи минимум 10-15 фото перед публикацией
  • Первые 3-5 постов — бесплатные (для привлечения)
  • Остальное — за подпиской
  • Добавляй watermark с username на все фото

10.5 Форматы

ТипФорматРекомендации
ФотоJPG/PNG, макс 50MBПортреты, сцены, образы
ВидеоMP4, макс 2GBWan 2.2 клипы 5-30 сек

  • Комиссия: 15% | Минимум: $20 | Еженедельно
