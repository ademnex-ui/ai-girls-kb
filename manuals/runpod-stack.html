Полный стек: AI-персонаж для Fanvue

От регистрации на RunPod до публикации готового контента. Для новичков — без опыта с ComfyUI.

🏗️ Архитектура стека

RunPod (арендованный GPU)
├── Pod 1: ComfyUI — генерация фото + анимация видео
│   ├── Z-Image Turbo NSFW checkpoint (генерация персонажа)
│   ├── FLUX 2 (face swap, финальное качество)
│   ├── Wan 2.2 Animate (анимация по видео-референсу)
│   └── ReActor нода (face swap)
└── Pod 2: Kohya_ss — обучение LoRA персонажа
    └── (запускаем только когда обучаем, потом выключаем)

Network Volume (постоянное хранилище $0.07/GB/мес)
└── Все модели, воркфлоу, датасеты — сохраняются между сессиями

ШАГ 0 — Подготовка RunPod (один раз)

0.1 Регистрация

  1. Идёшь на runpod.io
  2. Sign Up → вводишь email + пароль
  3. Пополняешь баланс: Billing → Add Credits → минимум $25-50 для старта
    • Оплата: крипта (USDT/BTC) или карта (через посредника если РФ)

0.2 Создание Network Volume (ВАЖНО — делается ДО Pod)

Network Volume = твой жёсткий диск в облаке. Модели скачиваются ОДИН РАЗ и остаются навсегда.

  1. В меню слева: Storage → Network Volumes
  2. Кнопка + Network Volume
  3. Настройки:
    • Name: ai-girls-storage
    • Size: 100 GB
    • Region: выбери тот же где будешь создавать Pod (EU-RO-1 или US-TX-3)
  4. Create → стоит ~$7/мес всегда (даже когда Pod выключен)

ШАГ 1 — Разворачиваем ComfyUI на RunPod

1.1 Создание Pod

  1. Pods → + Deploy
  2. GPU: ищи RTX 4090 → цена ~$0.74/час
    • Если недоступна → RTX A6000 (48GB) ~$0.79/час (даже лучше)
  3. Template: в поиске шаблонов пиши ComfyUI → выбери официальный "RunPod ComfyUI"
  4. Edit Template:
    • Container Disk: 20 GB
    • Volume Disk: оставь 0 (будем использовать Network Volume)
  5. Attach Network Volume: выбери ai-girls-storage
  6. Expose Ports: добавь порт 8188
  7. Deploy On-Demand → Pod запустится за ~2-3 минуты

1.2 Подключение к ComfyUI

  1. Когда Pod запустился → кнопка Connect
  2. Нажми HTTP Service [Port 8188] → откроется ComfyUI в браузере
  3. Видишь визуальный редактор нод = ComfyUI работает ✅

В RunPod нажми Connect → Start Web Terminal (или SSH)

ШАГ 4 — Обучение LoRA персонажа (Kohya_ss)

4.1 Создаём второй Pod

  1. Pods → Deploy
  2. GPU: RTX 3090 (24GB) ~$0.44/час или A40 (48GB) ~$0.76/час
  3. Template: ищи Kohya → "Kohya LoRA Training"
  4. Подключи тот же Network Volume ai-girls-storage

4.2 Установка Kohya_ss

cd /workspace
git clone https://github.com/bmaltais/kohya_ss
cd kohya_ss
pip install -r requirements.txt
python kohya_gui.py --listen 0.0.0.0 --server_port 7860 &

Открываешь порт 7860 в браузере → видишь веб-интерфейс Kohya

4.3 Подготовка датасета

mkdir -p /workspace/dataset/10_mygirl

Все 200 фото из шага 3 → загружаешь в папку /workspace/dataset/10_mygirl/
Число "10" = количество повторений на эпоху (стандарт для 200 фото)

4.4 Автоматический капшенинг

  1. Вкладка Utilities → BLIP Captioning
  2. Image folder: /workspace/dataset/10_mygirl
  3. Prefix caption: mygirl, (trigger word)
  4. Run Captioning → к каждому фото создастся .txt файл с тегами

4.5 Настройки обучения LoRA

ПараметрЗначениеПояснение
Base modelпуть к zimage-turbo-nsfw.safetensorsбазовая модель

Нажми Train → обучение займёт ~2-4 часа

4.6 Результат

В папке output появится файл mygirl_v1.safetensors (~50-150 МБ) — это твой персонаж.
Копируй его в /workspace/ComfyUI/models/loras/ на первом Pod.

ШАГ 5 — Генерация контента с персонажем

5.1 Тест LoRA

В ComfyUI → нода Load LoRA:

  • LoRA: mygirl_v1.safetensors
  • Strength: 0.8-1.0
  • В промпте обязательно: mygirl, (trigger word)

5.2 NSFW сцены

Добавляй в промпт описание сцены. Z-Image Turbo NSFW checkpoint уже разблокирован — не нужны специальные ключевые слова, просто описывай что нужно.

ШАГ 6 — Анимация видео (Wan 2.2 Animate)

6.1 Скачиваем видео-референс

На своей машине:

  • Используй SnapTik.app или SSSTik.io → вставь ссылку TikTok → скачай без водяного знака
  • Нужно видео с движениями без лица (танец, движения тела)

6.2 Workflow для Wan 2.2

Скачай готовый workflow: 👉 github.com/Wan-Video/Wan2.2/tree/main/examples

  1. Load → загрузи Wan 2.2 workflow
  2. Reference Image → твоё сгенерированное фото персонажа
  3. Reference Video → скачанное видео с движениями
  4. Generate → получаешь видео где твой персонаж повторяет движения

Время генерации: ~5-15 минут на RTX 4090 для 3-5 секундного клипа

ШАГ 7 — Face Swap (опционально)

Если хочешь взять реальное видео и заменить лицо на AI-персонажа:

В ComfyUI нода ReActor:

  • Source Face: фото твоего AI-персонажа (крупный план лица)
  • Target: видео или фото где нужно заменить лицо
  • Face Index: 0 (первое лицо в кадре)
  • Upscaler: GFPGAN или CodeFormer (для качества лица)
