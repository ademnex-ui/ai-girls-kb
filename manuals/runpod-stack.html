ШАГ 0

Подготовка RunPod (один раз)

0.1 Регистрация

  1. Идёшь на runpod.io
  2. Sign Up → вводишь email + пароль
  3. Пополняешь баланс: Billing → Add Credits → минимум $25-50 для старта
Оплата из РФ: крипта (USDT/BTC) — самый надёжный вариант. Подробнее в Шаге 10.7.

0.2 Создание Network Volume (делается ДО Pod)

Network Volume = твой жёсткий диск в облаке. Модели скачиваются ОДИН РАЗ и остаются навсегда — даже когда Pod выключен.
  1. В меню слева: Storage → Network Volumes
  2. Кнопка + Network Volume
  3. Name: ai-girls-storage | Size: 100 GB
  4. Region: тот же что и для Pod (EU-RO-1 или US-TX-3)
  5. Create → стоит ~$7/мес постоянно
ШАГ 1

Разворачиваем ComfyUI на RunPod

1.1 Создание Pod

  1. Pods → + Deploy
  2. GPU: ищи RTX 4090 (~$0.74/час). Если недоступна → RTX A6000 (48GB) ~$0.79/час
  3. Template: в поиске пиши ComfyUI → выбери официальный "RunPod ComfyUI"
  4. Edit Template: Container Disk = 20 GB | Volume Disk = 0
  5. Attach Network Volume: выбери ai-girls-storage
  6. Expose Ports: добавь 8188
  7. Deploy On-Demand → Pod запустится за ~2-3 минуты

1.2 Подключение к ComfyUI

  1. Pod запустился → кнопка Connect
  2. Нажми HTTP Service [Port 8188] → откроется ComfyUI в браузере
  3. Видишь визуальный редактор нод = ComfyUI работает ✅

Обучение LoRA персонажа (Kohya_ss)

4.1 Создаём второй Pod

  1. Pods → Deploy
  2. GPU: RTX 3090 ~$0.44/час или A40 ~$0.76/час
  3. Template: Kohya → "Kohya LoRA Training" (или RunPod PyTorch + ручная установка)
  4. Подключи тот же Network Volume ai-girls-storage

4.2 Установка Kohya_ss

cd /workspace
git clone https://github.com/bmaltais/kohya_ss
cd kohya_ss
pip install -r requirements.txt
python kohya_gui.py --listen 0.0.0.0 --server_port 7860 &

Открываешь порт 7860 → веб-интерфейс Kohya

4.3 Подготовка датасета

mkdir -p /workspace/dataset/10_mygirl

Все 200 фото из шага 3 → в папку /workspace/dataset/10_mygirl/
Число "10" = количество повторений на эпоху (стандарт для 200 фото)

4.4 Автоматический капшенинг

  1. Utilities → BLIP Captioning
  2. Image folder: /workspace/dataset/10_mygirl
  3. Prefix caption: mygirl, (trigger word)
  4. Run Captioning → к каждому фото создастся .txt с тегами

ШАГ 6

Анимация видео (Wan 2.2 Animate)

⚠️ Перед этим шагом — обязательно установи кастомные ноды Wan 2.2 (Шаг 9). Без них workflow не загрузится в ComfyUI.

6.1 Скачиваем видео-референс

На своей машине:

  • SnapTik.app или SSSTik.io → вставь ссылку TikTok → скачай без водяного знака
  • Нужно видео с движениями тела без крупного плана лица (танец, походка)

6.2 Workflow для Wan 2.2

👉 github.com/Wan-Video/Wan2.2/tree/main/examples

  1. Load → загрузи Wan 2.2 workflow
  2. Reference Image → сгенерированное фото персонажа
  3. Reference Video → скачанное видео с движениями
  4. Generate → персонаж повторяет движения
Время генерации: ~5-15 минут на RTX 4090 для клипа 3-5 секунд.

Face Swap (опционально)

Хочешь взять реальное видео и заменить лицо на AI-персонажа:

ШАГ 8

CivitAI: верификация 18+ NEW

Обязательно перед скачиванием NSFW моделей. Без верификации NSFW контент скрыт, API-ссылки вернут ошибку 401 Unauthorized.

8.1 Включить Mature Content

  1. Регистрируешься на civitai.com
  2. Профиль → Settings → Account
  3. Раздел Content Preferences → Mature Content
  4. Ставишь галочку: Show mature content (18+)
  5. Подтверждаешь возраст (просто галочка, без документов)
  6. Сохраняешь

8.2 API-ключ для скачивания через wget

  1. Профиль → Account Settings → API Keys → Add API Key
  2. Называешь ключ (например, runpod) → копируешь
  3. Используешь во всех wget командах:
wget --header="Authorization: Bearer ВАШ_API_КЛЮЧ" \
  -O "zimage-turbo-nsfw.safetensors" \
  "https://civitai.com/api/download/models/2221503?type=Model&format=SafeTensor"
ШАГ 9

Установка Wan 2.2 нод в ComfyUI NEW

Этот шаг обязателен перед Шагом 6. Без кастомных нод workflow Wan 2.2 просто не откроется в ComfyUI — будут ошибки "unknown node type".

В терминале Pod 1 (ComfyUI):

cd /workspace/ComfyUI/custom_nodes

# ComfyUI-WanVideoWrapper — основной пакет нод для Wan 2.2
git clone https://github.com/kijai/ComfyUI-WanVideoWrapper
cd ComfyUI-WanVideoWrapper
pip install -r requirements.txt

# VideoHelperSuite — для работы с видео (загрузка, сохранение клипов)
cd /workspace/ComfyUI/custom_nodes
git clone https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite
cd ComfyUI-VideoHelperSuite
pip install -r requirements.txt

Перезапускаем ComfyUI:

pkill -f "python main.py"
cd /workspace/ComfyUI
python main.py --listen 0.0.0.0 --port 8188 &
После перезапуска в ComfyUI появятся новые ноды в категории WanVideo и VideoHelperSuite.
ШАГ 10

Публикация на Fanvue NEW

Fanvue — OnlyFans-альтернатива, официально разрешающая AI-generated контент. Комиссия 15% (против 20% у OnlyFans).

10.1 Регистрация аккаунта создателя

  1. Идёшь на fanvue.com
  2. Sign Up → выбираешь Creator (не Fan)
  3. Email + пароль + username (выбирай имя персонажа — менять сложно)
  4. Верификация email

10.2 Верификация личности (обязательно для выплат)

  • Загружаешь паспорт/права (верификация на тебя как владельца, не на персонажа)
  • Selfie с документом
  • Срок проверки: 1-3 рабочих дня

10.3 Настройка профиля персонажа

  • Profile photo: лучшее сгенерированное фото (кроп лица)
  • Cover photo: широкий кадр 1920×1080
  • Bio: пишешь от лица персонажа (имя, история, характер)
  • Subscription price: $9.99–14.99/мес для старта
  • Важно: в bio укажи что контент создан AI — Fanvue этого требует

10.4 Стратегия первого контента

  • Загружай минимум 10-15 фото перед первой публикацией
  • Первые 3-5 постов — бесплатные (видны всем, для привлечения)
  • Остальное — за подпиской
  • Добавляй watermark с username на все фото
